# CLAUDE.md

Herculean is a workout log for people who train on a fixed weekly split, built by Minimalist. Treat it as a real product.

## Sources of truth

- UI spec: `docs/design/` (start with README.md). Refer to screens by ID, for example W10.
- Everything else: `docs/wiki/` (start with home.md). Don't repeat it here.

## Working together

- Short, plain sentences. Keep everything minimal, like the studio's name.
- Plan small, ask, then act. Propose, wait for approval, then do it. Don't overdo.
- Ask one batch of questions at a time, each with a recommendation.
- If the design looks wrong, report it with screen IDs. Never change the UI quietly: propose the design change and wait for approval.
- The wiki states only what is true now. Update it in the same PR as any change that affects it.
- Write each fact once, and link to it elsewhere.
- Ask before pushing anywhere (repo, wiki or any remote).
- Never merge PRs. The owner merges.
